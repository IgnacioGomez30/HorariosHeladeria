# Horarios de la heladería

**Especificación revisada para implementación · edición 1.1 · 25 de noviembre de 2026**

El encargado organiza una semana, comprueba quién estará en el local y decide qué horario confirmar. Puede armarlo a mano, pedir alternativas o reparar una semana ante una ausencia. El calendario confirmado conserva su versión hasta que el encargado aprueba otra.

**Cómo usar la entrega.** Descomprimir el ZIP completo antes de seguir los enlaces. La carpeta contiene los Markdown, el prototipo y un repositorio Git local con esta edición documentada. Abrir la carpeta como proyecto en Codex. Los ejemplos del contrato se leen junto con sus esquemas. Para recorrer las pantallas alcanza con abrir el HTML desde el explorador.

La fuente de partida es la especificación V1.0 del 25/11/2026 adjunta por el solicitante. Sus identificadores RF, RNF y T se conservan para poder cotejar cambios. El adjunto con información del equipo se mantiene por separado. En este repositorio se trabaja con identidades sintéticas. Las decisiones de diseño figuran como propuestas hasta su validación en las etapas indicadas.

**Estado.** Esta entrega cierra la revisión de diseño y deja preparado el comienzo de F1. La aplicación, las pruebas sobre sus binarios, la homologación del régimen de trabajo y el piloto corresponden a fases posteriores.
